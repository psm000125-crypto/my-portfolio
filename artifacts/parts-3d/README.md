# 관리 부품 3D 아카이브

`index.html`을 브라우저에서 열면 작동합니다. 모든 라이브러리를 함께 넣어 인터넷 연결 없이도 사용할 수 있습니다. 폴더 전체를 보관해 주세요.

포트폴리오에서는 **MIM 공정 품질관리 → 관리 부품 3D 아카이브**로 들어갑니다.

## 조작

- 마우스 왼쪽 드래그 / 한 손가락 드래그: 방향 제한 없이 회전
- 휠 / 두 손가락 핀치 / +, − 버튼: 확대·축소
- 방향키: 회전 (3D 화면에 포커스를 둔 상태)
- 기본 / 정면 / 윗면 / 아랫면: 시점 변경
- 자동 회전, 와이어 표시, 초기화: 하단 도구 모음
- 3D 파일 저장: 선택한 부품의 GLB 파일 다운로드

## 모델 범위

1. Wheel — 형상측정기로 반지름·길이·각도·곡률을 확인한 기록이 있는 부품
2. 유동 샤프트 H300 — 인턴 기록에 남은 실제 부품명
3. 경창 가이드 — 인턴 기록에 남은 실제 부품명
4. 밸브 슬리브 — 인턴 기록에 남은 실제 부품명
5. Nozzle Housing — 외형을 기준으로 붙인 포트폴리오용 명칭
6. Mounting Bracket — 외형을 기준으로 붙인 포트폴리오용 명칭

사용자가 제공한 사진의 외형을 참고해 코드로 작성한 실제 삼각형 메시입니다. 생성 이미지를 3D로 변환한 결과가 아닙니다. Wheel을 제외한 사진별 실물 부품명 대응은 기록만으로 확정할 수 없으므로, 유동 샤프트 H300·경창 가이드·밸브 슬리브는 인턴 기록에 나온 명칭을 연결했고 나머지 둘은 외형 기반 포트폴리오용 명칭을 사용했습니다. 사진으로 확인되지 않는 뒷면, 내부 형상, 치수는 추정했습니다. 모델 간 표시 크기는 관찰을 위해 정규화했으며 실제 상대 크기를 나타내지 않습니다. 제조·치수 검증을 위한 CAD 데이터가 아닙니다.

## 파일

- `models.js`: 부품의 형상을 만드는 코드
- `viewer.js`: 조명, 재질, 회전·확대, 선택 동작
- `models/*.glb`: 다른 3D 도구에도 가져올 수 있는 독립 모델 6개
- `export-glb.js`: GLB 내보내기 코드
- `vendor/three.min.js`: Three.js 0.160.1 (MIT, 동봉 라이선스 참조)

모델 재생성: 작업 폴더에서 `node work/build-parts-models.cjs`.

기술 참고: https://threejs.org/docs/ (LatheGeometry, ExtrudeGeometry, WebGLRenderer).
