# 편성민 원페이지 포트폴리오

## 열기

`index.html`을 브라우저로 열거나, 이 폴더에서 `node preview.mjs`를 실행하고 http://127.0.0.1:8766/ 에 접속합니다. 성과물은 로컬 파일로 포함되어 있습니다. 해당 포트가 사용 중이면 `PORTFOLIO_PREVIEW_PORT` 환경 변수로 다른 포트를 지정할 수 있습니다.

## 화면과 이동

- 왼쪽: 활동 시기를 표시한 최신순 경험 목록. 도장 AI PBL(2026.09), 조선·전기 교육(2026.07부터), Fe–Si 설계(2026.06 종료), 세종상권나침반(2026.05 종료), 운동 앱(2026.04 종료), MIM 인턴(2026.02 종료), X선 프로젝트(2025.12 종료).
- 중앙: 경험 개요. 항목을 선택하면 이야기 또는 성과물로 전환하고, 상단에 경험명과 개요 복귀 링크를 표시합니다.
- 오른쪽: 성과물과 경험 속 이야기 선택. 개요로 돌아가면 원래 크기로 복귀합니다.
- 지도·슬라이드의 크게 보기는 왼쪽 목록을 접습니다. 다시 누르거나 Escape로 복귀합니다.
- 슬라이드는 화살표 버튼, 페이지 선택 메뉴, 뷰어에 초점을 둔 상태의 좌우 방향키로 이동합니다.
- MIM 공정 이야기에서는 혼련·사출·탈지·소결 그림을 누르면 아래 설명이 전환됩니다. 별도 공정 탭 없이 그림 선택과 방향키·Home·End로 이동합니다.
- 검사 장비 사진 아카이브는 12개 장비를 치수·형상, 품질검사·중량, 경도·충격 세 묶음으로 한 페이지에 표시합니다. PC에서는 묶음마다 4열로 배치하며 사진을 누르면 원본을 크게 볼 수 있습니다.
- URL 해시로 경험과 세부 항목을 직접 열 수 있고, 브라우저 뒤로/앞으로 이동을 지원합니다.
- 작은 화면에서는 메뉴가 위에, 선택한 내용이 아래에 표시됩니다.
- 동작 줄이기 설정이 켜져 있으면 전환 애니메이션을 생략합니다.

프로필과 경험 개요·이야기·성과물 화면은 밝은 단일 바탕, 흑백 중심의 글자 위계와 얇은 구분선을 공유합니다. 중앙과 오른쪽의 큰 흰색 패널, 태그 테두리는 제거했습니다. 모든 경험의 텍스트 박스는 무채색으로 표시합니다. 그래프·도식의 데이터 표시는 자료별 비교 색을 사용하고 항목명과 수치를 함께 표시합니다.

9개의 경험 이야기는 짧은 문단별 탭을 없애고 본문과 시각 자료를 이어 읽는 구성으로 제공합니다. 원경험 자료에서 확인한 역할·공정·행동을 보강하고, 직접 만든 HTML/CSS/SVG 시편 관리표·공정 흐름·정량 결과 그래프를 문단 옆에 연결했습니다. PPT 이미지를 삽입했던 4곳은 도장 AI 예측 분포, XRD 시편 위치·분석 절차, CNT/GZCNT 계면 비교도로 교체했습니다. 측정 회절곡선을 임의로 재현하지 않습니다. MIM의 4개 공정 전환은 유지합니다. 별도 ‘근거의 범위’ 페이지는 제거했으며, 문헌 수치와 개념도는 그림 설명에서 출처와 성격을 표시합니다.

## 연결한 성과물

- 세종 상권 지도: 기존 독립 지도의 실제 검색·가중치·후보지 비교 기능. 임베드 복사본만 화면 크기에 맞게 조정했습니다. 원본 지도는 유지합니다.
- Fe–Si 설계: 공정 조건·핵심 Figure·측정 결과를 담은 1쪽 연구 요약 PDF.
- X선 분석: 개인정보를 제외한 발표자료 16장과 6쪽 프로젝트 요약 PDF. 대용량 원본 PPTX는 공개본에 포함하지 않습니다.
- 에너지재료설계: 팀원 이름·발표자 정보를 지운 공개용 슬라이드와 PPTX.
- 도장 AI: 원본 발표자료 10장, 예측 CSV의 검색·분류 필터, 최종 앙상블 구현 노트북.
- 도장 AI의 최종 F1 스코어 0.970905는 원경험 자료와 발표자료에 기록된 교육용 테스트 이미지 1,000건의 제출 결과입니다.

결과 발표자료 화면은 실제 PPT에서 내보낸 슬라이드를 원래 구성 그대로 제공합니다. 도장 AI 10장, X선 16장, 에너지 설계 24장이며 화살표·페이지 선택·키보드 이동·확대 기능과 원본 다운로드 링크를 제공합니다. 이야기에서는 핵심 요약의 결과 그래프·시각 자료를 필요한 문맥에 재사용합니다. 보존용 원본은 `경험들` 폴더에 유지합니다. 운동 앱과 현장 교육은 본문과 동작·공정 도식으로 소개하며, MIM 인턴에는 검사 장비와 사진 기반 추정 부품 3D 아카이브를 연결했습니다.

## 파일

운동 횟수 측정 경험에는 `artifacts/fitness-demo/`의 새 재현 데모를 연결했습니다. 원본 앱이나 과거 측정 데이터가 아니며, 기록된 z축 가속도·봉우리 검출 원리를 바탕으로 새로 구현한 포트폴리오용 프로토타입입니다. 일정한 동작과 빠른 동작의 시뮬레이션, 원신호·필터 신호 그래프, 임계값·최소 판정 간격 조정, 시작·정지·초기화를 지원합니다. 휴대전화 센서는 HTTPS·브라우저 지원과 사용자 허용이 필요하며, 실제 기기에서의 측정 정확도는 별도 검증 대상입니다. `node fitness-demo.test.mjs`로 재현 신호의 횟수·중복 검출 억제·초기화 등을 확인할 수 있습니다.

- `experience.js`: 경험 요약, 활동 시기, 세부 항목, 성과물 연결.
- `app.js`: 선택·전환·슬라이드·예측 결과 검색·코드 표시.
- `story-visuals.js`, `story-visuals.css`: 경험별 HTML/SVG 시각 자료, 데이터 색 체계, 무채색 텍스트 박스와 본문·도표 배치.
- `style.css`, `layout.css`, `ibm-theme.css`: 기본 배치와 전체 화면에 공통 적용한 밝은 바탕·타이포그래피·정보 위계. 기존 스타일 파일명은 유지합니다.
- `artifacts/`: 슬라이드 이미지, PPTX, 지도, CSV, Notebook.
- `build-og-preview.ps1`: 현재 시각 디자인에 맞는 공유 미리보기 이미지를 생성.
- `artifacts.js`: 슬라이드 목록.
- `artifact-data.js`: 예측 결과 및 코드 표시용 데이터.
- `build-artifacts.mjs`: 기존 지도에서 임베드용 복사본을 만들고 CSV·Notebook 표시 데이터를 생성.
- `export-artifacts.ps1`: 원본 발표자료용 기존 내보내기 스크립트입니다. 공개본 재생성에는 개인정보를 지운 사본을 사용해야 합니다.
- `preview.mjs`: 포트폴리오와 지정된 성과물만 제공하는 로컬 서버.

## 확인

JavaScript 문법, 성과물 파일 53개 존재, 페이지·지도·슬라이드 HTTP 응답을 확인했습니다. 브라우저에서 지도 가중치 입력과 후보 계산, 크게 보기와 복귀, 슬라이드 이동과 마지막 페이지, 예측 이미지 검색, 노트북 표시, 상세 이야기 전환을 확인했습니다.
